# 羽译 · Yuyi

[English](README.en.md) · [技术文档](docs/README.md) · [项目与发行版](https://github.com/ZOUYIQAQ/yuyi/releases)

**仅支持 Android 手机和平板。** 本 Fork 已移除其他平台客户端与专属工具，不提供 Windows、macOS 或其他平台版本。

基于 [KorenKrita/simul-subtitle](https://github.com/KorenKrita/simul-subtitle) 的安卓 Fork，原作者为 **KorenKrita**，由 **ZOUYIQAQ** 维护本分支，当前版本 **1.5.0**。保留原项目的 MIT 版权与许可声明。应用包名为 `io.github.zouyiqaq.yuyi`，可与原版 `io.github.korenkrita.simulsub` 共存，数据与权限独立。

默认图标采用用户提供的矢量轮廓，保留变色背景、山茶花与飘落装饰。在「设置 → 外观」选择彩色或纯色样式、背景及飘落花瓣；开关同时控制右下绿叶。纯色提供10种预设色，默认跟随主题相近色，也可手动固定。支持 Android 自适应裁切与系统主题图标。

在 Android 上识别正在播放的声音，通过你自己的翻译 API 显示悬浮字幕。语音识别与静音检测在设备本地运行，翻译服务接收文字。支持手机和平板；仓库只保留 Android 产品及其共享核心。

## 开始使用

需要 **Android 10（API 29）及以上、arm64-v8a** 设备。安装 APK 后：

首次打开会依次引导配置**必要权限 → 翻译 API → 识别模型**，每一步都可跳过，之后可在设置里补齐或重开引导。开始同传前需要：

1. 允许录音和悬浮字幕。通知为可选；系统屏幕共享授权会在每次开始时询问。
2. 保存自己的翻译 API 地址、模型 ID 和密钥。可选择预设后修改，再点「保存翻译配置」；测试草稿不会自动保存。
3. 在「设置 → 模型库」下载并启用一个识别模型。每包包含静音检测，校验完成后点击「启用模型」。
4. 返回「同传」选好语言和场景，点击底部「开始同传」。

音频采集受来源 App 的采集策略、DRM、系统版本及设备实现影响，不能保证所有播放器或内容都可采集。系统授权界面也可能因设备不同而不同；当前采集未按单个进程隔离，其他允许内录且同时发声的应用可能混入字幕。

## 模型与翻译

| 识别模型 | 原声语言 | 完整下载量（含 VAD） |
|---|---|---|
| ReazonSpeech | 日语、英语 | 77,745,395 字节，约 74.1 MiB |
| SenseVoice Small | 中文、英语、日语、韩语、粤语 | 240,193,589 字节，约 229.1 MiB |

APK 不内置 ASR 或 VAD 权重。模型下载到应用私有目录，校验字节数与 SHA-256 后才可手动启用；同传运行期间不能切换模型，需停止后切换。许可文本以 APK 的 `assets/licenses/` 随包提供，并非与模型下载到同一目录。详情见[模型说明](docs/asr.md)和[来源核查](docs/MODEL_SOURCES.md)。

翻译 API 提供 DeepSeek 官方、硅基流动、OpenRouter 预设，也支持自定义 OpenAI 兼容聊天接口。预设仅填写草稿，不保存、不请求网络，所有字段均可修改；跨端点切换预设会清空草稿里的旧密钥、自定义请求头和 User-Agent。OpenRouter 需要自行填写模型 ID。连接测试只测试草稿，发现可用完整地址后可在页面内选择「替换并保存」，不点就保持原配置；未保存离开会再次确认。默认值与官方来源核查日期为 **2026-10-15**，服务商可随时调整；这不代表已验证你的付费账户或 API。详见[翻译配置](docs/translation.md)。

新安装默认使用从图标原图取色的「山茶」暖色主题：橙棕主色、奶油背景，搭配山茶红和鼠尾草绿。同传主操作固定在导航栏上方，滚动时仍可点击；手机按钮至少72dp，平板限宽480dp并靠右。运行后原位切换为「停止同传」。已有手动配色会保留。启动时的人物图标没有插画底色，启动页整页背景随应用配色和明暗模式变化。

## 常用设置

- **同传**：选择原声、译文语言和场景，切换「仅显示定稿」。原声选项随已启用模型变化；目标语言也可自行填写。
- **设置 → 场景与术语**：编辑入口，编辑背景、固定译名，或调用自己的翻译服务生成术语；生成后需检查并保存。
- **字幕**（设置也可进入）：配色、字号、透明度、宽高与字幕保留方式。默认只显示译文、不显示耗时；原文和耗时可独立开启。非仅定稿模式在黑框外固定预留实时草稿区域，避免底部浮窗随草稿出现消失而抖动。显示限制二选一：默认「按句数」保留最近3句，可选1–10句（包含草稿）；「按字数」保留最多10–300个译文字数，按Unicode码点计数，超长句保留最新尾部。没有行数、最少句数或字数阈值叠加；实际可见内容仍受屏幕及字幕框物理尺寸约束。只影响显示，不改日志、原始定稿或翻译上下文。页面内的可拖动悬浮预览持续更新，可切换横屏/竖屏画幅。
- **设置 → 外观**：海蓝、松绿、鸢尾、山茶、蔷薇、岩灰六色，也可输入任意六位十六进制颜色或使用色相、饱和度、明度滑杆自定义，Android 12 及以上可动态取色，旧系统回退所选配色。浅色、深色或跟随系统独立设置，应用外观与字幕配色分开。
- **设置 → 高级设置**：结合上文翻译、衔接重复字处理、Jev 智能断句与译文检查。Jev 默认关闭，开启后发送文字到第三方服务，可能计费或限速。
- **设置 → 系统权限**：查看和调整录音、悬浮字幕与通知授权；首页仅提示尚未完成的必要权限。
- **设置 → 使用记录**：默认关闭，只有主动开启才保存文字 JSONL 记录、分享、确认删除单条或确认清空。正在写入的记录受保护，不能分享或删除。

点按实际字幕可展开工具栏，拖动移动，展开后拖四角调整大小；支持锁定与停止。可在「字幕样式」重置位置。

## 更新与构建

「设置 → 应用更新」：默认在启动时检测更新，可关闭自动检查，也可手动检查；支持稍后提醒、跳过指定版本和恢复提醒。更新按钮通过浏览器打开本 Fork 的 GitHub APK 下载链接，缺少 APK 时打开[发布页](https://github.com/ZOUYIQAQ/yuyi/releases)，不在应用内下载或安装。发行版列表以GitHub实际发布为准。

自行构建见[构建与开发](docs/build.md)。当前构建入口为 `:core` 与 `:app`，不分发 macOS / Windows 版本。
