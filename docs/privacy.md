# 隐私说明

本文描述当前仅支持 Android 的客户端。桌面客户端及其专用工具已移除。

## 本地数据

- 播放音频通过 Android `AudioPlaybackCapture` 获取，交由本地 ASR 与 VAD 处理；当前采集流水线不上传或保存原始音频，不读取麦克风音源。
- APK 不含 ASR/VAD 权重。每个识别模型包各自包含 Silero VAD，需在「模型库」下载、逐文件校验后手动启用，存放在私有 `files/models/<模型标识>/` 下；识别时从本地读取。许可文本另以 APK `assets/licenses/` 随包提供。
- 「设置 → 使用记录」默认关闭。开启后记录文字、提示词与运行指标，不含原始音频、API Key 或自定义请求头值；文件在应用专属外部目录 `Android/data/io.github.zouyiqaq.yuyi/files/logs/`。
- 翻译 API Key、自定义请求头值及 Jev Key 使用 Android Keystore 加密保存。应用关闭系统备份；这不意味着设备上的所有设置字段均为加密字段。

## 联网行为

| 触发操作 | 接收方 | 发送或获取内容 |
|---|---|---|
| 模型库手动下载 | 清单指定的 `modelscope.cn`、`hf-mirror.com`、`huggingface.co`；Silero VAD 另有 GitHub 发布源 | 获取固定文件，按固定字节数与 SHA-256 校验。不附带音频、字幕、使用记录或翻译密钥 |
| 实时翻译 | 用户配置的 OpenAI 兼容聊天服务 | 当前识别文字、场景背景、适用的术语表、启用后的定稿原文上下文，以及必要的修正提示；携带该服务的密钥、User-Agent 与自定义请求头 |
| 测试连接与首次关闭思考参数探测 | 用户配置的翻译服务 | 固定测试文本及提示词、服务凭据，最多尝试 6 种参数，可能计费 |
| 生成术语 | 用户配置的翻译服务 | 场景、背景及已有术语等生成所需文字，携带该服务凭据 |
| 开启 Jev 辅助后判断 | 所选 OpenCode Zen、TypeSafe 官方或 OpenRouter Jev 端点 | 断句使用原文；译文检查使用原文与译文，按渠道要求携带 Jev Key，不发送音频 |
| 关于页手动检查更新 | `api.github.com` | GET `https://api.github.com/repos/ZOUYIQAQ/yuyi/releases/latest`，获取发行标签；不附带字幕、使用记录或翻译密钥 |
| 点击项目、模型来源或许可链接 | 外部浏览器或可处理链接的应用 | 打开对应网页；后续网页联网行为由外部应用和站点处理 |
| 分享使用记录 | 用户在系统分享面板选择的应用 | 授权该应用读取所选日志文件 |

第三方服务会接收到常规连接信息，例如网络 IP；对文字的留存与使用以接收方政策为准。翻译 API 预设仅修改草稿，不保存或发起请求；跨端点应用预设时清空草稿旧密钥、请求头和 User-Agent，保存前已有配置不变。

当前关于页没有启动时自动检查、应用内更新下载或安装、更新代理回退，也没有跳过版本或关闭自动检查开关。「打开项目仓库」是独立操作，由外部应用打开项目页。

## 使用记录管理

可在「设置 → 使用记录」分享已结束记录，或确认删除单条、确认清空记录。删除不可恢复；正在写入的记录不能分享或删除，清空会保留活动记录或删除失败的记录，不中断当前同传。关闭记录开关不会清除既有文件。日志含真实原文、译文与提示词，分享前请确认接收方，详见[使用记录](logs.md)。

## 权限与采集范围

| 权限或系统授权 | 当前用途 |
|---|---|
| `RECORD_AUDIO` | 系统内录要求的授权；采集播放音频，不采集麦克风 |
| `MediaProjection` 系统授权 | 授权播放音频采集，界面随系统和设备而异 |
| `SYSTEM_ALERT_WINDOW` | 在其他应用上方显示字幕 |
| `POST_NOTIFICATIONS` | 前台服务、停止操作和下载状态通知 |
| `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PROJECTION` | 维持字幕采集服务 |
| `FOREGROUND_SERVICE_DATA_SYNC` | 系统管理的模型下载前台工作 |
| `INTERNET`、`ACCESS_NETWORK_STATE` | 模型下载、翻译、Jev、手动查询发行版及网络状态 |
| `REQUEST_INSTALL_PACKAGES` | Manifest 中保留的旧更新权限，当前关于页不调用应用内安装流程 |

能否采集受来源应用策略、DRM、系统与设备限制，不能承诺任意播放器均可采集。当前采集匹配 `USAGE_MEDIA`、`USAGE_GAME`、`USAGE_UNKNOWN`，没有按单个应用进程隔离。其他允许内录且同时播放的声音也可能被识别并发送给翻译服务；使用期间应暂停不希望被识别的音源。
