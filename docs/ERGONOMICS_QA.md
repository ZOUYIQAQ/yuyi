# 羽译手机与平板逐项验收

## 1.8.1首页精修补验（2026-10-16）

启动卡缩短为内容高度，横向主按钮至少72dp、最多360dp，仍避开底部字幕；平板保留独立右栏，低矮宽窗并排显示状态与按钮。两个裸文字入口改为带图标的描边按钮。手机、横平板及两种200%字号实拍已逐图核对，窄屏入口自动折行且可滚动触达。新增两行状态的短窗回归，先复现遮挡再修复通过；335项单元测试、45项最终设备用例与Lint／Release构建通过。原速真实字幕组件演示视频与GIF见[本轮记录](ANDROID_QA.md)。


## 1.8.0控制区与字幕过渡补验（2026-10-16）

手机实拍与真实听译链路确认开始／停止位于首屏中部，不被默认底部字幕遮住；平板右侧独立控制卡保留紧凑按钮，字幕预览默认左下。手机115项去重最终结果、平板48项专项与335项单元测试通过。高度按已绘制帧推进，连续调整衔接已呈现高度；拖动缩放跟手，临时字幕和工具栏显隐不移动正式末行。详见[本轮设备记录](ANDROID_QA.md)。

本轮目标：从首次使用、日常观看和修改配置三种实际任务出发，逐页检查真实像素与操作过程，发现问题直接修复。保留已有主题、图标、模型独立下载、字幕贴底和正式字幕基线防抖。

## 验收标准

- 手机主操作首屏可见，至少72dp高；普通操作至少48dp触控范围。
- 页面标题、返回和关键动作不被系统栏、键盘、字幕预览或底部导航遮住。
- 手机、平板横竖屏、窄窗及200%字号下文字可读，内容可滚动，控件不挤压或越界。
- 设置选中状态、禁用状态、保存与未保存、下载与失败均清楚；不依赖颜色单独表达。
- 返回与切换页面保留阅读位置；未保存配置有保护，破坏性操作有确认。
- 视觉结论来自实际渲染；付费服务与未连接设备不冒充已经实测。

## 证据与接续

### 验收发现与处理

- 窄屏和大字号下，主题三等分按钮、色板及图标摘要容易挤压。模式改用整行单选，色板随实际栏宽与字号调整列数，摘要在空间不足时独占一行。
- 图标与自定义颜色摘要使用完整列宽，修复非整数像素密度下自然宽度取整引起的末尾溢出；保留逐项文字排版与触控范围断言。
- 自定义颜色对话框在大字号窄栏纵向排布色值及主题效果；图标手动色样的整项触控高度至少48dp。
- 字幕设置保留额外底部滚动余量，确保最后一项能完整移到「恢复预览」悬浮按钮上方；不改变实际字幕窗口及其贴底、防抖逻辑。
- 高级设置的辅助服务密钥保存后回填，切换服务后读取各自保存的值；可核对、编辑与显式清空，仍使用可逆加密。
- 首页服务名称在窄屏大字号时独占一行，管理入口另起一行，避免英文模型名称被挤成碎行。
- 工具栏拆为独立系统窗口后补齐触摸计时：手指按住时暂停自动隐藏，松开或取消后重新计时；真实4.2秒长按回归先失败、修复后通过。
- 关于页移除重复仓库卡，保留独立Fork维护者入口、原作者、上游与完整MIT许可。

### 测试夹具边界

- 常规页面遍历操作真实MainActivity、读取真实授权与已安装模型；不下载新模型、不删除现有模型、不保存测试API。
- 首次引导、下载中／失败／校验、新版本、命名API和样例记录等状态由真实正式组件接隔离内存状态渲染，动作确实回填；不冒充已发生线上下载、付费翻译、记录分享或版本发布。
- 早期失败保留：懒列表未组合项需先滚动定位；对话框有独立输入服务，完成动作需由当前字段发出；截图需等待页面合成，不能把前一页缓冲区当作当前页面。这些测试修复未修改产品业务行为。

- 实拍与隔离状态截图统一保存在`.qa/ergonomics/`，逐图记录实际观察，不向说明书增加重复图库。
- 专用本地API35／ARM64模拟器；只操作`emulator-5580`。
- 用户偏好先备份；实际模型及旧包保留。隔离夹具不访问真实凭据、不调用付费API。
- 验收后恢复手机尺寸、字号、旋转和用户偏好，再构建可覆盖旧测试包的APK。
- 提交推送沿用此前授权；本轮不创建Release或发行标签。

## 本轮结果（1.6.1，2026-10-16）

- 手机以1080×2400／420dpi、100%字号完成常规页面实拍和九类隔离旅程；840×1866／420dpi为实际320dp窄窗，以系统200%字号复验引导、外观、字幕和首页。模型名称挤压修复后重新验证为完整一行。
- 平板以2560×1600／240dpi完成常规页面逐列遍历及九类旅程；补1536×960／240dpi的低矮窗口200%字号、1600×2560竖屏的首页和字幕预览。逐图检查实际布局，配合控件位置、文字排版、触控尺寸和状态回填断言。
- 设备主批次89项中，87项通过；两项窗口快照在前一页重排未结束时取到旧位置。改为被动等待真实坐标稳定，保留全部逐帧基线与贴底像素断言。最终手机字幕窗口、真实键盘和API旅程4项通过；平板字幕窗口、真实键盘、API旅程及预览15项通过。批次重复用例不相加成唯一总数。
- 平板九类旅程初轮8项通过，API新增夹具因非空请求头默认展开、测试又寻找展开入口而失败；修正操作顺序后重验。中间一次系统截图临时返回空帧，改为两秒有界取帧重试，所有页面和业务断言保留。
- 新增抽屉高速手势回归。在1536×960平板窗口的原实现中，长列表上滑后触发持续重排并超时；修复顶部安全区与锚点的尺寸反馈后，普通／200%字号、常规平板均通过。保留官方手势和动画，不固定所有抽屉高度、不升级实验依赖。手机同组件与API／字幕流程3项复验通过。
- 工具栏展开后的整屏证据须等待系统合成完成；测量或OnDraw回调不代表已出现在系统截图中。已逐图确认实际工具栏可见，并比较展开前后正式白字边界。按住工具栏4.2秒的回归在原实现失败，修复后普通与沉浸模式均通过。
- 核心253项、应用64项单元测试通过；Lint为0错误、225警告，没有通过忽略或降级处理。最终安装包采用压缩Release构建和原测试证书，保留可覆盖安装能力。

以上均为同一本地API35／ARM64模拟器的不同真实窗口配置。普通页面操作真实MainActivity；下载失败、新版、记录和填写API等难复现状态使用正式组件加隔离内存数据。未把这些界面状态当作真实线上下载、付费翻译质量、实体平板或浏览器分享成功的证明。模型与原有业务配置保留；日志和原始截图位于`.qa/ergonomics/`。

- 最后以真实物理滑动确认320dp／200%字号颜色对话框的HSV滑杆、两项主题效果及固定保存／取消均可达。未保存测试颜色；原始偏好353份逐文件恢复比对一致，手机尺寸、100%字号与旋转设置恢复。
