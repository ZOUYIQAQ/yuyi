# 用量费用与两步选择

## 目标

1. 首页与引导以听写服务、翻译服务两个真实选择控件替代三模式按钮；直译服务显示已包含翻译。
2. 展示今天、上次同传及运行中本次的预计费用，独立于字幕记录开关。
3. 长期保存每次回报的供应商、模型、时间、数字用量与费率快照，支持后续按小时／任意时段统计；不保存字幕、音频或密钥，不自动清理历史。
4. 累计用量幂等，失败与取消不虚构零费用，未知单价或缺失用量明确未计价。
5. 手机、平板真实交互/视觉、至少一分钟真实听译验证后打包并安装开发设备；不提交推送发布。
