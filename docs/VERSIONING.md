# 版本规则

羽译采用[语义化版本规范 SemVer](https://semver.org/lang/zh-CN/)，版本格式为 `主版本号.次版本号.修订号`。

- 不兼容的功能、配置或接口变更，递增主版本号，后两位归零；例如移除已提供的听译模式。
- 向下兼容的新功能，递增次版本号，修订号归零。
- 向下兼容的 Bug 修复，递增修订号。

每次应用功能改进或 Bug 修复，不论多小，交付的新安装包都必须使用新 `versionName`，并将 Android `versionCode` 递增。相同版本已经交付后，不覆盖为其他内容。一次迭代中尚未交付的修正可以合并进同一个新版本。

`app/build.gradle.kts` 是版本的唯一配置来源。更新时同步写明更新内容，APK 文件名和关于页须与实际构建版本一致。版本变化不意味着获得提交、推送或发布授权。

本次从 `1.9.0` 改为 `2.0.0`、`versionCode=38`：移除“省钱分段”模式属于不兼容的功能移除；旧配置、平台密钥和费用历史保留并迁移。

`2.1.0`、`versionCode=39`：新增可选的字幕自动宽度，保留已有固定宽度与默认值，因此递增次版本号。

`2.1.1`、`versionCode=40`：修正模型参考数字与来源说明，按修订号递增。

`2.1.2`、`versionCode=41`：补齐ReazonSpeech上游实测错误率并标明来源，按修订号递增。

`2.2.0`、`versionCode=42`：新增两路简化引导、自动保存密钥与全局下载反馈，按兼容新功能递增次版本号。

`2.3.0`、`versionCode=43`：本地引导新增模型目录发现与自动配置，按兼容新功能递增次版本号。

`2.3.1`、`versionCode=44`：修复本地引导的下载触发、排列与过期操作提示，递增修订号。

`2.4.0`、`versionCode=45`：新增钥匙扣列表、弹窗编辑和确认删除，压缩翻译服务卡片，按兼容新功能递增次版本号。

`2.4.1`、`versionCode=46`：修复服务卡片身份不清和主导航过渡方向，递增修订号。
