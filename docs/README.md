# 使用与技术文档

安装与快速上手见[中文首页](../README.md)或[英文首页](../README.en.md)。当前构建仅支持 Android 手机和平板；桌面客户端与专用工具已移除。

设置首页按「字幕与翻译」「个性化」「应用」分组列出条目，点入对应的独立详情页，返回由顶栏与系统返回统一处理。界面编排参考 FlClash 的 Material You 层级与卡片组织，保留本项目自身的 Compose 技术栈，使用官方 Compose Material3 1.4.0 稳定组件；容器描边与分割线按层级使用，同一层级保持一致。

## 应用更新

「设置 → 应用更新」默认在启动时检测更新，支持关闭自动检查、手动检查、稍后提醒、跳过指定版本和恢复提醒。更新按钮通过浏览器打开本 Fork 的 GitHub APK 下载链接，缺少 APK 时打开[发布页](https://github.com/ZOUYIQAQ/yuyi/releases)，不在应用内下载或安装。发行版列表以GitHub实际发布为准。

截图文件与设备验收记录分别维护；截图展示不等于所有设备、音源或付费翻译服务已通过验收。

界面截图为羽译 1.5.0 在 2026-10-15 本机 API 35 模拟器的真实截图，平板图按平板窗口验收，未冒充实体设备。字幕样式图为设置预览。

外观支持任意RGB十六进制输入及HSV调色，确认后保存。桌面图标仅保留矢量彩色、纯色两种样式，背景与飘落装饰独立；默认彩色、插画背景和飘落花瓣，开关同时控制右下绿叶。纯色可选颜色并默认匹配主题。

字幕显示策略互斥选择按句数（默认）或按译文字数，不再叠加行数、区间下限或字数阈值。新安装默认仅译文、无耗时，按句数保留最近3句。可拖动悬浮预览随参数更新，支持横屏/竖屏画幅切换，离开页面后销毁。场景编辑有固定左上返回按钮。

羽译使用独立包ID`io.github.zouyiqaq.yuyi`，不会覆盖旧hinome包或自动读取其数据。测试连接不自动保存，只有明确替换或保存才应用；未保存退出会确认。非仅定稿模式的实时草稿预留在字幕黑框外，启动页图标也使用独立透明背景的人物资源。

首次打开仅引导权限、翻译API和下载启用模型，每步可跳过。完成后不再自动显示，设置可重新打开。主导航为同传／字幕／设置；首页不展示会话文本，文件记录仅在主动开启保存后生成。
