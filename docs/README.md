# 使用与技术文档

安装与快速上手见[中文首页](../README.md)或[英文首页](../README.en.md)。当前构建仅支持 Android 手机和平板；桌面客户端与专用工具已移除。

本轮版本为 **羽译1.7.0（versionCode 31）**，正常合并上游1.0.4的短语快速分句、按时间戳补回漏词及短片段翻译优化；保留临时字幕背景预留，包含命名 API 配置、HTTP 本机／局域网服务和草稿增量翻译，并改善窄屏／大字号外观与辅助服务密钥回填；原作者与提交来源见[架构](architecture.md)。

默认场景为「B站 VTuber 直播」，已保存的手动选择和场景编辑内容会保留。

## 应用更新

「设置 → 应用更新」默认在启动时检测更新，支持关闭自动检查、手动检查、稍后提醒、跳过指定版本和恢复提醒。更新按钮通过浏览器打开本 Fork 的 GitHub APK 下载链接，缺少 APK 时打开[发布页](https://github.com/ZOUYIQAQ/yuyi/releases)，不在应用内下载或安装。发行版列表以GitHub实际发布为准。

截图文件与设备验收记录分别维护；截图展示不等于所有设备、音源或付费翻译服务已通过验收。

以上4张图片为羽译1.7.0于2026-10-16在本机API35模拟器的实际截图，含平板窗口尺寸。字幕样式图为设置预览。

外观支持任意RGB十六进制输入及HSV调色，确认后保存。桌面图标仅保留矢量彩色、纯色两种样式，背景与飘落装饰独立；默认彩色、插画背景和飘落花瓣，开关同时控制右下绿叶。纯色可选颜色并默认匹配主题。

「预留临时字幕空间」默认关闭，开启后草稿消失仍保留一行背景；仅在关闭「仅显示定稿」后可调整，置灰期间保留选择。字幕显示策略互斥选择按句数（默认）或按译文字数，不再叠加正式字幕行数、区间下限或字数阈值。新安装默认仅译文、无耗时，按句数保留最近3句定稿，另保留最新1条草稿。可拖动悬浮预览随参数更新，支持横屏/竖屏画幅切换，离开页面后销毁。场景编辑有固定左上返回按钮。

羽译使用独立包ID`io.github.zouyiqaq.yuyi`，不会覆盖旧hinome包或自动读取其数据。测试连接不自动保存，只有明确替换或保存才应用；保存后保留输入，密钥默认隐藏并可用右侧眼睛切换明文，显示「已保存」，未保存退出会确认。正式与临时字幕共用一个连续圆角背景，临时字幕紧随定稿，间距2dp且始终最多一行；开启原文时在同一行合并原文与译文。窗口固定预留草稿预算，草稿显隐不改变正式最后行基线。工具栏为独立浮层，显隐不挪动主字幕。启动页图标使用独立透明背景的人物资源。

命名配置独立保存地址、模型、密钥、User-Agent 和请求头，旧配置沿用「默认」；删除须确认且至少保留一套，未保存切换须先确认放弃。运行中选中空配置继续使用原服务，完整配置在后续句子生效。草稿首次直接翻译，之后相对最后入队文本累计变化至少5个 Unicode 码点再翻译，定稿不受限制。1.5.1 的真实布局透明尾部、可见系统栏和字幕基线防抖修复保留。

首次打开仅引导权限、翻译API和下载启用模型，每步可跳过。冷启动时读取系统真实授权状态，必要权限缺失时在首页顶部显示强调卡，全部授予后隐藏。完成引导后不再自动显示引导，设置可重新打开。主导航为同传／字幕／设置；首页不展示会话文本，文件记录仅在主动开启保存后生成。
