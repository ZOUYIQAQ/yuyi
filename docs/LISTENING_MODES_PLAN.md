# 更多模型与云端听译

本轮从正式版 v1.8.4 开始，保留现有安卓界面与字幕防抖，增加三条完整使用路径。

## 能力与实现顺序

| 模块 | 责任 | 依赖 |
| --- | --- | --- |
| local-models | 增加 Whisper Tiny 多语种、Moonshine Tiny 英语与日语；固定文件、按需下载、校验和真实解码 | 现有模型仓库与 sherpa |
| cloud-protocol | 千问实时听译：音频直接换取原文与译文，无需本地识别模型或另配文字翻译 API | OkHttp WebSocket |
| listening-modes | 模式持久化、独立云端凭据、前台录音服务按模式启动 | cloud-protocol |
| mode-setup | 首次引导选择模式，按选择只展示必需配置；设置与首页可再次切换 | listening-modes、local-models |

先并行实现模型与云端协议，再接入服务、控制器与界面，最后回归。

## 产品约束

- 旧用户保持本地模式，保存的模型、翻译 API、主题、字幕与记录不变。
- 新用户授权后选择「本地识别」「在线听译」或「在线听写＋翻译」，每步均可跳过。
- 本地模式需要模型和文字翻译 API；在线模式只需云端服务配置，不下载或加载本地模型。
- 云端接入千问 LiveTranslate，默认大陆接入点；模型从已支持的实时版与省钱分段版中下拉选择，地址可编辑。密钥可回填、默认隐藏且可切换查看，沿用 Android Keystore 可逆加密。
- 明确在线模式会把播放音频发送给所选服务；只在用户开始时连接，不后台测试或付费重连。测试只验证连接与配置，不发送录音。
- 运行中不能切换模式及云端连接配置；停止后及时取消连接、缓冲与迟到字幕。
- 云端使用自己的语言支持范围；不把本地场景、任意目标语言或在线辅助冒充为云端能力。
- 模型卡保留简短介绍、语言、大小与许可，不编造准确率或安卓速度。
- 保留字幕默认译文、三句、自动高度、紧凑单行草稿与全部防抖/动画。
- 本轮只修改并提供可测试安装包，不自动更新已经发布的 v1.8.4 附件。
